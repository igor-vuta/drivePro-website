## Motion and accessibility

These are generated rendered 3D illustrations animated with CSS, not interactive 3D meshes or business photographs. The supplied parent-owned transparent artwork uses intrinsic aspect ratios 1536×1024 (excavator) and 1254×1254 (moped). Responsive 360/720 variants are selected by native picture sources under the existing Pages base path, with AVIF first and WebP fallback. Combined AVIF sizes are 29,604 / 72,759 bytes; unchanged WebP fallbacks are 66,462 / 188,440 bytes. Both formats preserve the same artwork and layout ratios. Original PNGs remain evidence rather than shipped assets; the parent retains asset provenance and hash records.

The small client enhancer changes only motion state after both images decode. SSR starts at the complete static composition. A 1.8 second transform/opacity arrival moves from ±64 px desktop / ±28 px mobile with a gentle 3-degree rock; there is no loop, audio, timer, delayed CTA or forced focus. Hover/focus uses a separate restrained lean. Hidden-page state, reduced motion, media failure and intentional pointer/keyboard interaction settle the greeting. Returning to a hidden page never replays it. Failed images are hidden while labels/helpers/actions keep the destination usable.

Each entire choice is one semantic Link with visible action wording and `data-destination`. Header languages, contacts and compact footer links have at least 44 px targets. The skip link targets `#welcome`, whose section can receive focus. Artwork is decorative because adjacent labels explain each category; it has empty alt and an assistive-tech-hidden visual wrapper. Intrinsic dimensions and reserved image stages protect layout. No JavaScript/reduced motion preserve the same complete links/content. No runtime dependencies are added.
